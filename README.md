# מנוע בינת הטבע — גרסה 3.0

מנוע אחד חי, עם פירוק הידע לשלושה קבצים ו-prompt caching על החלק היציב.

## מבנה הפרויקט

```
nature-engine/
├── core/                      הגרעין התשתיתי — אין בו מהות טבע
│   ├── anthropic-client.js    הקריאה אל קלוד + prompt caching
│   ├── db.js                  PostgreSQL — שמירה וטעינת שיחות
│   └── knowledge-loader.js    מרכיב את שלושת קבצי הידע לבלוק אחד
│
├── knowledge/                 בסיס הידע — "המודל" שמשתפר
│   ├── 01-identity.md         זהות · עקרונות-על · מודל ההתכנסות · קהל יעד
│   ├── 02-flow.md             עשרת השלבים · שער האבחון · מבחן המציאות
│   └── 03-rules.md            מה לא לעשות · מבנה תשובה · מדרג גמישות
│
├── knowledge-archive/         גרסאות קודמות של הידע (להשוואה לאורך זמן)
├── public/
│   └── index.html             ממשק המשתמש
├── server.js                  נקודת הכניסה — מחברת הכל
├── package.json
└── .env.example
```

## איך המטמון עובד

הקובץ `core/anthropic-client.js` שולח את בלוק הידע (שלושת הקבצים מחוברים) בתוך `system`, ומסמן אותו ב-`cache_control`. בקריאה הראשונה הוא נכתב למטמון; בקריאות הבאות (בתוך 5 דקות) הוא נקרא במחיר מוזל. רק היסטוריית השיחה וההודעה החדשה נשלחות במחיר מלא.

## הפעלה מקומית

```
npm install
cp .env.example .env      # ומלא את המפתח וכתובת המסד
npm start
```

## פריסה ב-Render

הגדר שני משתני סביבה בשירות:
- `ANTHROPIC_API_KEY`
- `DATABASE_URL` (ה-Internal Database URL של מסד ה-PostgreSQL)

הטבלה `chats` נוצרת אוטומטית באתחול.

## שיפור המודל

כדי לשפר את המנוע — ערוך את הקבצים בתיקיית `knowledge/`. לפני שינוי גדול, שמור עותק של הקובץ הנוכחי ב-`knowledge-archive/` עם תאריך, כדי שתוכל להשוות. אחרי השינוי, קרא ל-`POST /api/reload-knowledge` כדי לטעון מחדש בלי הפעלה מחדש של השרת.
